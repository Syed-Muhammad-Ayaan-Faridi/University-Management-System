How to read: run the program (make, then ./ums) and type the Input values in
order, pressing Enter after each one. ">" separates the values. Every case
starts from a fresh program with the sample data (24 students, 11 courses,
8 faculty); delete any ums_*.txt files first. "..." means more lines follow
on screen. <time> is a timing value that changes on every run.
All cases were run on the real program; the output below is what it printed.
